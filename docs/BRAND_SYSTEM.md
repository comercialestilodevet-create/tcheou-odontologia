# Brand System — Tcheou Odontologia

## Posicionamento

Odontologia boutique na Tijuca, com uma comunicação que equilibra precisão, acolhimento e sofisticação.

## Assinatura

**Tcheou Odontologia. Onde precisão e carinho andam lado a lado.**

## Paleta

| Função | Valor |
|---|---|
| Off-white | #F6F2EA |
| Areia | #EEE7DC |
| Carvão | #1B2524 |
| Madeira | #2C221C |
| Turquesa | #08A6B5 |
| Turquesa profundo | #087F89 |

## Tipografia

**Manrope** para títulos e interface.  
**DM Sans** para texto corrido.  
**Georgia** como contraste editorial pontual.

## Princípios de UI

1. Espaço em branco é elemento de luxo.
2. Turquesa aparece como assinatura, não como preenchimento dominante.
3. Madeira cria calor e percepção de consultório boutique.
4. Bordas arredondadas devem parecer arquitetônicas, não infantis.
5. Movimento deve ser lento, curto e funcional.

## Tom

Humano, seguro, elegante e claro. Falar com o paciente, não com o profissional.

Evitar:
- superlativos absolutos;
- promessa de resultado;
- urgência artificial;
- excesso de emojis;
- jargão clínico desnecessário.
